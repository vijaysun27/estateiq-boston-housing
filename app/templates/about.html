About EstateIQ

An educational machine learning web application demonstrating rigorous regression modeling, schema validation, and fair AI principles.

Project Overview & Architecture

Production-grade Flask application with decoupled ML inference.

EstateIQ demonstrates the end-to-end lifecycle of a machine learning application: from historical dataset acquisition and validation, through reproducible cross-validation and pipeline serialization, to web deployment via an Application Factory pattern.

The inference engine loads the serialized pipeline (StandardScaler + GradientBoostingRegressor) once per process during application startup, ensuring zero retraining latency during HTTP request handling.

Ethical Feature Policy: Exclusion of Variable 'B'

Commitment to fair AI, legal compliance, and ethical data science standards.

The original 1978 study dataset contained a 13th feature designated as B, computed as 1000(Bk - 0.63)^2, where Bk represented the proportion of Black residents in each town.

In accordance with fair housing regulations, non-discrimination laws, and modern responsible AI principles:

  • Variable B is strictly omitted from user interfaces and HTTP API endpoints.
  • In Phase 2, the production Scikit-Learn pipeline was trained exclusively on the 12 non-demographic features, eliminating the variable from all model weights.
  • Any attempts to submit variable B via the API are rejected by strict schema validation.

Historical Limitations & Non-Appraisal Notice

Essential caveats regarding 1970s benchmark observations.

The Boston Housing benchmark reflects census tract metrics collected in 1970. Over the past 50+ years, metropolitan Boston has experienced substantial demographic shifts, zoning transformations, and macroeconomic inflation.

Critical Notice: Valuations produced by EstateIQ represent historical 1970 median valuations in thousands of US dollars ($1,000s). They are intended solely for academic study of regression algorithms and must never be interpreted as contemporary financial, mortgage, or property appraisals.
