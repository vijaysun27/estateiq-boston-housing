# EstateIQ Model Registry

This directory contains trained model artifacts and preprocessing scalers for the EstateIQ application.

---

## 1. Managed Artifacts

### `boston_housing_model.keras`
- **Origin**: Trained in [ANN For Regression.ipynb](file:///c:/Users/Vijay/Documents/ProITBridge/Deep_Learning/Chapter8_ANN_for_Regression/ANN_for_regression/ANN%20For%20Regression.ipynb).
- **Format**: Keras v3 Native Zip format (`.keras`).
- **Input Dimension**: `(None, 13)` continuous normalized features.
- **Output**: Single continuous scalar `(None, 1)` representing `MEDV` in thousands of dollars.
- **Architecture**:
  - `Dense(64, activation='relu')`
  - `Dense(32, activation='relu')`
  - `Dense(16, activation='relu')`
  - `Dense(1)` (Linear regression output)

### `scaler.joblib`
- **Origin**: Serialized `sklearn.preprocessing.StandardScaler` fitted on the Boston Housing training distribution.
- **Purpose**: Scales raw input features to zero mean and unit variance (`z = (x - u) / s`) before executing the neural network forward pass.
- **Guarantee**: Serializing the fitted scaler eliminates the need to refit the scaler or download/access training data during web server startup.

### `boston_housing_pipeline.joblib` (Planned for Phase 2)
- **Origin**: Generated by `scripts/train_model.py` in Phase 2.
- **Format**: Complete Scikit-Learn `Pipeline` containing preprocessing and regression estimator trained exclusively on the 12 canonical features.

## 2. Server Startup & Loading Lifecycle

1. The Flask application never trains or re-fits models upon startup or during HTTP requests.
2. During `create_app()` execution, `PredictorService` attempts to locate and load the available model artifact into memory once per worker process.
3. If no artifact is present, the service sets `is_ready() -> False` and responds with HTTP `503 Service Unavailable` on prediction requests rather than failing startup catastrophically.
